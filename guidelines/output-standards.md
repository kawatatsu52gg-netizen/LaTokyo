# 出力基準

全エージェント共通の品質基準。

## 必須項目

### 冒頭サマリ
- 200字以内で「何を作ったか」を要約
- 次に詳細を続ける

### 出典・根拠
- 数値・主張・引用は出典を併記
- 出所不明なら「出所不明」と明記
- 推測は「推測」と明記

### 前提の明示
- ターゲット・媒体・目的を冒頭で確認・記載
- 不明点は推測せず質問する（または保留扱い）

### 分かりやすさ
- 1段落1主題
- 専門用語には簡単な解説を添える
- 数字は3桁区切り（¥1,234,000）

## 禁止事項

- 嘘・捏造（数値・出典・症例）
- 効能断定・治療をうたう表現
- 他者批判
- 個人情報の露出（顧客・受講者・クライアント）
- 内部機密（売上・契約条件）の対外開示

## フォーマット規約

### 文体
- 日本語（特に指定がない限り）
- 敬体（です・ます調）
- 「である」調は教育資料など限定的に

### 見出し
- Markdown 見出し（# ～ ###）を活用
- 1ページ内で見出し階層を飛ばさない

### 箇条書き
- 3〜7項目程度を目安
- 長くなる場合は見出しで分割

### 数値
- 単位・期間・出所を明示
- 「前月比 +12%（2026年4月→5月、SalonBoard集計）」のように

### コード・引用ブロック
- 設定値・テンプレ・引用文はコードブロックに

## 完成基準

producer 系エージェントは出力前に以下を自己チェック：

1. ターゲット・目的・媒体が明示されているか
2. 主張に根拠があるか
3. 禁止事項に触れていないか
4. テンプレに沿っているか（該当する場合）
5. 川辺が読んで違和感がないか

reviewer 系はこの自己チェック結果も評価する。
