# エスカレーションルール

エージェントが**作業を止めて川辺に確認する**ケースを明文化する。
迷ったら止める。

## 必ず川辺確認（司令塔経由）

### 金銭
- 広告予算の±20%以上の変更
- 新規契約（業者・提携先・コンサル契約）
- メニュー価格の変更
- セミナー受講料の設定・変更
- コンサル料の提示（特に月額30万円超）

### 公開・対外
- SNS・YouTube の最終公開判断
- セミナー LP / 告知ページの公開
- プレスリリース・取材対応文面
- メディア掲載原稿の最終確認

### ブランド
- ブランドトーンの根本変更
- ロゴ・店舗名・サービス名の変更
- 4事業を越える新規事業の立ち上げ
- 既存事業の撤退・縮小

### 倫理・炎上リスク
- 他者批判を含む発信
- ジェンダー・政治・宗教・健康論争に踏み込む発信
- 個人特定可能な症例の使用
- 過去発言・他社引用の使用

### 法務
- 医療広告ガイドライン抵触の可能性
- 著作権・肖像権が絡む素材
- 個人情報を含むデータの外部送信
- 契約書・利用規約・プライバシーポリシーの文面

### リソース
- 川辺の臨床時間を週5h以上増減させる提案
- 川辺の登壇予定（セミナー・取材・コンサル現場）の追加・変更

## 自動で進めてよい

- 内部資料の整理・整形
- 既存テンプレ準拠の草案作成
- データ集計・可視化
- 既存メニューの告知文ドラフト（公開は別判断）
- セミナー資料の構成案（最終確定は川辺）

## エスカレーションの形式

エージェントから司令塔への報告：

```
## 川辺確認推奨
- 件名:
- 理由: （該当ルール）
- 候補案: A / B / C（あれば）
- 期限: 〇月〇日まで
```

司令塔から川辺への提示：

```
## 確認お願いします
- 件名
- 背景（1〜2文）
- 選択肢（A / B / C）と推奨
- 影響範囲
```

## 川辺の不在時

川辺の返答がない場合、エージェント側で勝手に進めない。
「保留中」として記録し、再開時に最初に提示する。

## 例外: 軽微な誤字修正

明白な誤字・脱字・リンク切れ等は確認不要で修正してよい。
ただし**修正したことは報告**する。
