# SNS発信ルール

X・Instagram・YouTube の共通ルール＋媒体別ルール。

## 共通原則

1. **発信前に必ず content-reviewer を通す**
2. **公開判断は川辺**（エージェントは下書きまで）
3. **押し売り / 煽り / 他者批判 / 効能断定 は禁止**
4. **エビデンスがある主張は出典を添える**

## トーン

### 川辺の一人称
- 「私」を基本。「俺」「僕」「自分」は不使用

### 語彙の温度
- 患者・顧客向け: やわらかい敬体
- 20代施術家向け: 落ち着いた敬体（先輩として）
- どちらも「フランクすぎる」より「やや丁寧」寄り

### 禁止語（再掲）
- 絶対 / 必ず / 最強 / 神 / ヤバい
- バズる / 完全保存版 / これだけ知れば
- 治る / 完治 / 治療

## 媒体別ルール

### X（旧Twitter）

- 1ツイート 140字以内
- スレッドは3〜7ツイートまで
- ハッシュタグは最大2個、または不使用
- 引用RTで他者批判しない
- 「炎上しそうな話題」へのコメントは控える
- 数字主張には出典を添える
- 「臨床のメモ」「学びの共有」「事業の告知」を主軸

### Instagram

- 本文の最初の1〜2行で要点
- ハッシュタグは本文と段落を分けて下部にまとめる（20〜30個）
- カルーセル想定なら「[画像1] / [画像2]」のように構成指示
- ストーリーズは即時性の高い情報（営業・告知・裏側）
- リール想定は別途台本テンプレに従う

### YouTube

- タイトルは検索意図を意識（煽り禁止）
- サムネは「過剰な驚き顔・赤文字」を避ける
- 概要欄: タイムスタンプ / 関連リンク / 出典
- 台本は時間目安付き（[0:00-0:30]）
- BGM・効果音の権利確認は別途

## 発信軸（コンテンツテーマ）

### 20代施術家向け（主に X / YouTube）
- 臨床知見（解剖学・神経系・触診）
- 経営観（独立・集客・接客）
- キャリア論（失敗談含む）
- 学習法・読書・推薦文献

### 患者・顧客向け（主に Instagram / 各事業アカウント）
- 不調と日常生活のつながり（自律神経・姿勢）
- セルフケア（押し付けない範囲で）
- サロンの世界観・スタッフ紹介
- 告知（メニュー・キャンペーン）

## 投稿頻度の目安

- 厳密なノルマは設けない
- 質を優先。量を稼ぐための薄い投稿はしない
- 連投よりも、1投稿の完成度を上げる

## 川辺と無関係の発信

- 時事ニュースへのコメントは原則しない
- 芸能・政治・宗教は触れない
- 例外: 業界・健康・教育に関わる公的トピックで、川辺の専門性が役立つ場合
  → 必ず川辺確認

## エラー対応

- 誤字・事実誤認に気づいたら静かに修正
- 大きな誤りは「先ほどの投稿に誤りがあったため修正しました」と一言添える
- 削除する場合は川辺確認
