# セミナー設計プロトコル（HALII ACADEMY）

HALII ACADEMY のセミナー資料・教育コンテンツを作るときの共通ルール。

## 設計原則

1. **学習目的（learning objective）を冒頭に明示**
2. **エビデンスと臨床経験を分けて書く**
3. **手技は再現可能性を最優先**
4. **受講者を尊重する語り口**

## 学習目的の書き方

各セミナーの冒頭で：

```
## 本セミナーの学習目的
受講後、受講生は以下ができるようになる：
1. 〇〇を説明できる
2. 〇〇を触診で識別できる
3. 〇〇の施術手順を再現できる
```

「分かる」ではなく「できる」レベルで書く。

## 標準構成

### 90分セミナー
- 導入（5分）: 学習目的・自己紹介・本日の約束
- 講義パート1（25分）
- ワーク or 実技（25分）
- 講義パート2（20分）
- 質疑応答（10分）
- まとめ・宿題（5分）

### 半日（4時間）
- 90分パート × 2 + 休憩・実技拡大

### 1日（6〜7時間）
- 午前: 解剖・理論
- 午後: 実技・症例
- クロージング: 復習・課題

## スライド原稿ルール

### 1スライド1メッセージ
- 1スライドで主張を1つに絞る
- 補足は講師トークで

### 文字情報量
- 1スライドの表示テキストは80〜120字程度
- 図解で代替できるものはテキストにしない

### スライド原稿テンプレ

`templates/seminar-structure.md` 参照。

## エビデンスの扱い

### 引用の形式
- 著者(年). タイトル. 雑誌名. のような形式
- 不明な場合は引用しない（曖昧引用 NG）
- 「最新の研究では」と書くなら必ず文献名を添える

### 臨床経験ベースの主張
- 「私の臨床経験では」「現場で観察される範囲では」と明示
- 統計的根拠と臨床経験の混同を避ける

### 否定的データの併記
- 効果が限定的・否定的なエビデンスがあれば併記する
- 「すべて効く」「万能」のような誇張をしない

## 手技説明のルール

### 必須要素
- 部位（解剖学的名称で）
- 接触点（皮膚 / 筋腹 / 腱 等）
- 方向（屈曲・伸展・回旋等を明示）
- 力加減（軽 / 中 / 強、または kg目安）
- 持続時間（秒）
- 頻度（回数）

### NG例
- 「優しく押す」「感じながら」のみ → 力加減・時間が抜けている
- 「気を整える」「波長を合わせる」→ 検証不能な表現

## 受講者への語り口

### OK
- 「先生方の臨床に役立てば幸いです」
- 「私はこう考えていますが、検証してみてください」

### NG
- 「これを知らない施術家は」
- 「私のやり方が唯一の正解」
- 「秘伝」「私だけが知る」

## 配布資料

- スライドPDF＋ハンドアウト（要点まとめ）
- 復習チェックリスト
- 参考文献リスト
- 質問フォーム or 連絡先（過剰な営業導線にしない）

## 受講後フォロー

- アンケート（学習目的の達成度を測る項目を含める）
- 復習動画の提供（任意）
- 過剰な追加販売の押し付けはしない

## 改訂

- 受講者アンケート結果は次回改訂に反映
- エビデンスのアップデートを年1回以上見直し
