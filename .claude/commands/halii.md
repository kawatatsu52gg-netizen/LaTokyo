HALII ACADEMY（ボディワーク教育）の依頼として処理してください。

1. `halii-designer` を Agent tool で起動して教育コンテンツを作らせる
2. 出力を `halii-reviewer` に渡して評価させる
3. NEEDS_REVISION なら halii-designer に差し戻し（最大2周）
4. 告知文・LPが必要なら `content-writer` を並列起動

依頼内容:
$ARGUMENTS

留意点:
- エビデンスベース。出典のない断定は禁止
- 「秘伝」「私だけが知る」等の権威化表現は禁止
- 再現可能な手技説明（角度・力加減・秒数）を求める
- 受講者を見下さない
