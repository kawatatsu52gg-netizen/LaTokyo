# 再来DM・LINE文面テンプレート

## 入力欄

- 対象店舗: LaTokyo / Flourb
- 配信タイミング: 来店翌日 / 1週間後 / 1ヶ月後 / 3ヶ月離脱
- 対象顧客タグ: 新規 / 再来 / VIP / 離脱
- 配信媒体: LINE公式 / SMS / メール

## 文面ルール

- 川辺自身が書いている雰囲気を保つ（テンプレ感を出しすぎない）
- 「絶対」「最後」「今だけ」を使わない
- 「無理にご来店いただかなくても」と添える
- 1通の中で押し売りに見える誘導は1箇所まで
- 絵文字は最小限。ビジネスメール的トーン
