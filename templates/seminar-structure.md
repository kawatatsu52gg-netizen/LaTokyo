## カリキュラム概要

### 90分パターン

| 時間 | パート | 内容 |
|---|---|---|
| 0:00-0:05 | 導入 | 自己紹介・学習目的・本日の約束 |
| 0:05-0:30 | 講義1 | ...（解剖・理論） |
| 0:30-0:55 | 実技1 | ...（触診・手技） |
| 0:55-1:15 | 講義2 | ...（症例・応用） |
| 1:15-1:25 | 質疑応答 | |
| 1:25-1:30 | まとめ | 復習・宿題・次回案内 |

### 半日（4時間）パターン
- 90分パート × 2 + 休憩・実技拡大

### 1日（6〜7時間）パターン
- 午前: 解剖・理論
- 午後: 実技・症例討論
- クロージング: 振り返り・課題

```
  「本文...」

- 補足図解: 必要 / 不要
  - もし必要: [図解: 〇〇の解剖図]

- 出典: 著者(年). 文献名.
```

## 配布資料

- スライドPDF
- ハンドアウト（要点まとめ・3〜5ページ）
- 復習チェックリスト
- 参考文献リスト

## 受講後フォロー

- アンケート（学習目的の達成度を測る項目を含む）
- 復習動画リンク（任意）
- 次回セミナーの案内（押し売り禁止）

## 講師の留意点

- 「秘伝」「私だけが知る」等の権威化表現を使わない
- 他流派批判をしない
- 受講生の質問に「初歩的すぎる」等の反応をしない
- 時間管理（質疑応答時間を確保）

## 自己チェック

- [ ] 学習目的が明示されている
- [ ] 出典のない断定がない
- [ ] 手技説明に方向・力加減・秒数がある
- [ ] 質疑応答時間がある
- [ ] 復習資料がある
- [ ] 権威化表現がない
