# YouTube 企画書テンプレート

## 動画基本情報

- **動画タイトル候補（3案）**
  1. ...
  2. ...
  3. ...
- **想定尺**: 7〜10分 / 15分 / 20分以上
- **チャンネル**: 川辺個人 / HALII / LaTokyo（事業別）
- **公開予定**: YYYY-MM-DD

## ターゲット

- 主要視聴者: 20代施術家 / 40〜50代女性患者 / 経営者層
- 視聴の動機: 学びたい / 解決したい / 知りたい

## 動画の目的（1つに絞る）

- [ ] 知識提供（教育）
- [ ] サロン認知拡大
- [ ] セミナー集客
- [ ] コンサル問い合わせ獲得
- [ ] チャンネル登録者増

## 競合・参考動画

- 関連動画3〜5本のURL（あれば）
- 参考にする構成・差別化ポイント

## 動画構成（章立て）

```
0:00 オープニング・自己紹介・本日のテーマ（〜60秒）
0:60 結論先出し（30秒）
1:30 本論パート1（タイトル）
4:00 本論パート2（タイトル）
6:30 本論パート3（タイトル）
8:30 まとめ
9:00 視聴者への一言＋次の動画予告
9:30 終了
```

## サムネイル案

- 構図: 川辺の表情 + キャッチコピー / 図解 + テキスト
- 文字: 12字以内（読める大きさで）
- 過剰演出（赤文字・驚き顔・矢印連発）はしない
- カラー: ブランドカラーに準拠

## 概要欄構成

```
[1〜2文の動画要約]

[タイムスタンプ]
0:00 オープニング
0:60 結論
...

[出典・参考文献]
- ...

[関連リンク]
- LaTokyo: https://...
- HALII: https://...

[SNS]
- X: ...
- Instagram: ...
```

## 検索キーワード（SEO）

- 主軸キーワード（1〜2語）
- 関連キーワード（5〜10語）

## CTA（行動喚起）

- チャンネル登録 / 高評価のお願いは1回まで、押し付けない
- 概要欄リンクへの誘導
- セミナー・サロン・コンサルの告知は控えめに（押し売り禁止）

## リスク・確認事項

- 引用素材の権利
- 出演者・場所の許諾
- 医療広告ガイドライン
- 川辺確認が必要なポイント

## 自己チェック

- [ ] タイトル案が3つある
- [ ] ターゲットと目的が明示
- [ ] 結論先出しの構成
- [ ] 出典・参考リンクを概要欄に
- [ ] 煽りサムネになっていない
