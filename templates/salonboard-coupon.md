# SalonBoard / ホットペッパー クーポン文テンプレート

## 入力欄

- 対象店舗: LaTokyo / Flourb
- クーポン種別: 新規 / 再来 / 期間限定 / オプション
- 対象メニュー: ...
- 価格設定: 通常 ¥... → クーポン ¥...
- 利用条件: ...
- 有効期限: ...

---

## クーポン名（タイトル）

### LaTokyo（新規）例
```
【初回限定】自律神経ケアコース 60分 ¥9,800（通常¥13,200）
```

タイトル原則:
- 「初回限定」「再来様限定」を冒頭に
- メニュー名と時間と価格を明示
- 「通常価格」を併記（割引感を出すが煽らない）
- 「驚愕」「衝撃」「とんでもない」は使わない

---

## 内容説明（本文）

```
[共感パート]
眠りが浅い、肩こりが取れない、なんとなくだるい。
このような不調は自律神経のバランスと関係していることがあります。

[コース内容]
当店の「自律神経ケアコース」は以下の流れで行います。
- カウンセリング（10分）
- 頭蓋骨調整 / 骨盤調整（40分）
- 整理・アフターケアの説明（10分）

[期待できる変化（断定しない）]
施術後に「呼吸が深くなった」「お身体が軽い」と
おっしゃる方が多くいらっしゃいます（個人差があります）。

[ご案内]
40〜50代のお身体の変化に寄り添うコースです。
お気軽にご相談ください。
```

---

## 利用条件

```
・初めてご来店の方限定
・他クーポンとの併用不可
・ご予約時に「自律神経ケアコース」とお伝えください
・キャンセル/変更は前日までにお願いいたします
```

---

## 禁止表現

- 「絶対に治る」「効果絶大」「驚愕の効果」
- 「他院ではできない」「業界初」「日本一」
- 「今だけ」連発 / 不安煽り
- 過剰な医療用語（病名表現の断定）

---

## 自己チェック

- [ ] タイトルに「初回限定」等の対象が明示
- [ ] 通常価格との対比が明確
- [ ] 効能を断定していない
- [ ] 個人差の注記がある
- [ ] 押し売り感がない
- [ ] 利用条件が明示されている
- [ ] 医療広告ガイドラインに違反しない
