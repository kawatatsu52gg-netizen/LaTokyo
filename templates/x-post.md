# X 投稿テンプレート

## 入力欄（依頼時に埋める）

- 媒体: X（旧Twitter）
- 対象アカウント: 川辺個人 / LaTokyo / Flourb / HALII
- ターゲット: 20代施術家 / 患者・顧客
- 目的: 学び共有 / 告知 / 問いかけ / 雑感
- 文字数制約: 単発（140字以内） / スレッド（3〜7本）
- 含めたい要素: ...
- 含めない要素: ...

---

## 単発投稿フォーマット

```
[フック1行]
[本文（事実 or 経験）]
[気づき or 一言]
（必要なら）#ハッシュタグ最大2個
```

### 例: 20代施術家向け

```
施術後に「肩楽になりました」と言われると、つい技術の話を考える。
でも実際は来店までの不安が抜けただけ、ということもある。
触れる前の空気作りも臨床の一部。
```

---

## スレッド構成（3〜7本）

```
1/n [問い or 結論先出し]
2/n [事実・背景]
3/n [私の解釈]
4/n [補足 or 反例]
5/n [まとめ・呼びかけ（押し売りなし）]
```

### スレッドのコツ
- 1本目で続きを読みたくなるが、煽らない
- 各ツイートが単独で読めるように書く
- 最終ツイートで「いいね」「RT」依頼はしない

---

## 出典付き主張の書き方

```
[主張]
（出典: 著者(年) or 文献名）

私の解釈は[コメント]。
```

---

## 自己チェック

- [ ] ターゲット・目的が明示されている
- [ ] 140字以内 / スレッドなら7本以内
- [ ] ハッシュタグ最大2個
- [ ] 「絶対」「最強」「神」「バズる」等を使っていない
- [ ] 効能断定をしていない
- [ ] 他者批判をしていない
- [ ] 川辺の一人称は「私」
- [ ] 出典 or 経験の限定を添えている
