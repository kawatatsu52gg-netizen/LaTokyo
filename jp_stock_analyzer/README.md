# 日本株ファンダメンタル分析ツール

IRBANK を主データ源に、日本株の **EPS 長期右肩上がり判定(A/B/C)** と
**100点満点のファンダメンタルズ採点** を自動化するツールです。
`stocks.txt` に銘柄コードを書き換えるだけで対象を変更できます。

## できること

- 過去約10年の EPS + 最新予想 EPS を取得し **A / B / C** で判定
- PER / PBR / ROE / 配当利回り / 営業利益率 / 自己資本比率 / 営業CF を取得
- 100点満点で採点し ★ で5段階ランク付け
- `stock_analysis.csv` と `report.md`(Markdown レポート)を出力
- 取得できなかった銘柄はスキップし、最後にエラー一覧を表示

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

```bash
# stocks.txt の全銘柄を分析
python analyze.py

# 動作確認:先頭5銘柄だけ
python analyze.py --limit 5

# リクエスト間隔を調整(相手サイトへの配慮。既定 1.5 秒)
python analyze.py --sleep 2.0

# 補完ソースの ON/OFF
python analyze.py --no-yahoo --no-kabutan
```

出力:
- `stock_analysis.csv` … コード / 会社名 / EPS評価 / PER / PBR / ROE / 営業利益率 /
  自己資本比率 / 営業CF / 配当利回り / 総合点 / ランク / コメント
- `report.md` … A/B/C 評価表・A/B/C 別一覧・総合評価表・★ランキング・エラー一覧

## 銘柄の変更

`stocks.txt` を編集するだけです(1行1コード、`#` はコメント)。

```
1605
6902
9101
# 368A のような英字入り新コードもそのまま書けます
368A
```

## 判定・採点ロジック

判定と採点は `eval_core.py` の**純粋関数**に切り出してあり、ネットワーク非依存で
単体テストできます。

```bash
python eval_core.py   # => eval_core selftest: OK
```

### EPS 判定 (A / B / C)

| 評価 | 条件 |
|---|---|
| **A** | ほぼ毎年 EPS 増加。減少は1回だけかつ軽微(10%以内)。非常にきれいな右肩上がり |
| **B** | 途中で減益の年があるが回復し、**過去最高 EPS を更新**。長期では右肩上がり |
| **C** | 乱高下 / 赤字あり / 長期で増えていない / 30%超の急減を繰り返す景気循環株 |

### 100点満点の配点

| 項目 | 配点 |
|---|---|
| EPS 右肩上がり | 40 |
| ROE | 20 |
| 営業利益率 | 15 |
| 自己資本比率 | 10 |
| 営業CF | 10 |
| 配当利回り | 5 |

ランク: ★★★★★(90+) / ★★★★☆(80–89) / ★★★☆☆(70–79) /
★★☆☆☆(60–69) / ★☆☆☆☆(59以下)

## 構成

| ファイル | 役割 |
|---|---|
| `stocks.txt` | 分析対象の銘柄コード一覧 |
| `analyze.py` | メイン。取得→判定→採点→CSV/レポート出力 |
| `datasource.py` | IRBANK / Yahoo / 株探 からの取得・HTML解析 |
| `eval_core.py` | 判定・採点の純粋関数(単体テスト付き) |
| `requirements.txt` | 依存ライブラリ |

## 注意

- スクレイピングは各サイトの利用規約・`robots.txt` の範囲で、`--sleep` で間隔を
  空けて実行してください。
- HTML 構造はサイト側の変更で崩れることがあります。`datasource.py` はセレクタ
  決め打ちを避け「ラベル一致 + 年度行」で総当たり探索する設計ですが、取得できない
  項目は `None`(レポート上は `-`)になります。
- 実行環境からの外向き通信がブロックされている場合(社内プロキシや隔離サンドボックス
  等)は全銘柄がスキップされます。ネットワークが到達可能な環境で実行してください。
