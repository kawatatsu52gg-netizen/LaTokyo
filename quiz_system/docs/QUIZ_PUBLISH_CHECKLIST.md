# クイズ公開チェックリスト

`approve` する前に、1問ずつ確認する。1つでも✗があれば公開しない（修正 or rejected）。

## 1. 正確性・出典
- [ ] 参照 claim はすべて `verified`（needs_review/rejected を含まない）
- [ ] `source_ids` と `claim_ids` が紐づき、出典（動画/論文/教科書）まで辿れる
- [ ] エビデンスレベルが表示され、**D ではない**（公開は原則 B 以上、俗説の訂正はC可）
- [ ] 解説と正解が矛盾していない

## 2. 設問の質（QA自動チェック＋目視）
- [ ] 正解が一つに限定される（曖昧でない）
- [ ] 4つの選択肢がそろい、各不正解の説明がある
- [ ] 選択肢の文章量から正解が推測できない（長さの偏りが無い）
- [ ] 「すべて正しい」「どれでもない」を使っていない
- [ ] 重複問題ではない

## 3. 表現・価値観
- [ ] 教材の主張文に「必ず/全員/絶対」等の過度な断定が無い
       （誤り選択肢としての断定は可。解説で否定していること）
- [ ] 性的に煽る表現・テクニック偏重になっていない
- [ ] 女性を一括りにしていない（個人差の注記がある）
- [ ] 反応・痛み・オーガズムに触れる問題は、同意・安全の注記がある
- [ ] 成人向け教育として適切

## 4. スコア（自動）
- [ ] QAレポートで **公開可（⛔が無い）**
- [ ] 6観点採点（/30）に要修正が無い
- [ ] 10観点レビュー（/100）が **85点以上**（`review` の公開候補に含まれる）

## 5. 承認操作
- [ ] 医療者（または責任者）の最終確認を得た
- [ ] `python -m src.pipeline approve Q-xxxx` を実行し `approved/` に移動
- [ ] draft に残っていない（承認前後が混在しない）

## 重大な差し戻し基準（該当したら即 rejected）
- 医学的な誤り／出典不足／正解の曖昧さ／同意・尊重に反する表現。

## 記録
- 問題ID / 章・レベル / 判定(approve or reject) / 確認者 / 日付 / 差し戻し理由（あれば）
