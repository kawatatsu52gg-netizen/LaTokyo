# 学習の最終ゴール（卒業要件）

> **ミッション**：知識を覚えることではなく、女性の身体を正しく理解し、
> 相手を尊重しながら安心して話し合えるパートナーを育てること。

このゴールは `data/goals.json` を正本とし、すべてのレッスン・クイズ・図解・
ストーリー・ゲーム・コンテンツがここに貢献しているかを監査する（`goals-audit`）。

## 卒業時に身につける6つの能力
| ID | 能力 | 説明 |
|---|---|---|
| **G1** | 基本構造を説明できる | 女性の身体の基本構造を、やさしい言葉で自分の言葉として説明できる |
| **G2** | 個人差が大きいと理解している | 感じ方・形・反応には大きな個人差があり『みんな同じ』ではないと分かる |
| **G3** | 心理・環境・体調が関わると理解している | 身体の反応は身体だけでなく心理・環境・体調にも左右されると分かる |
| **G4** | 相手と安心して会話できる | 身体や気持ちを、相手が安心できる形で会話・共有できる |
| **G5** | 決めつけず本人に聞ける | 分からないことを思い込みで決めつけず、本人に確かめられる |
| **G6** | 知識を思いやる行動につなげられる | 尊重・我慢させない・受診の後押し等、思いやりの行動に変えられる |

## コンテンツ→能力の対応（設計方針）
| コンテンツ | 主に貢献する能力 |
|---|---|
| 4択/穴埋め/応用クイズ（KB由来） | G1（＋個人差注記でG2） |
| 初心者レッスン（平易化） | G1・G2・G6 |
| 学習ゲーム（3レベル） | Lv1→G1／Lv2→G1・G3／Lv3→G4・G5・G6（全問にG2・G6を保証） |
| 感情モジュール（empathy） | G2〜G6（相手の気持ち・会話例・学び） |
| 患者向け/ブログ/スライド等 | G1＋安全・個人差（G2・G6） |

## 監査（goals-audit）
```bash
python -m src.pipeline goals-audit      # 整合率・能力別カバレッジ・要対応を出力
```
- 各コンテンツが 6能力のどれに触れているかをキーワードで判定。
- **貢献ゼロ**の項目は「非貢献」として要対応に挙げる（修正または削除）。
- **学習者に直接届くコンテンツ**（初心者クイズ・ゲーム・感情モジュール）は、
  最低でも **G2（個人差）と G6（思いやり）** を含むことを必須にする。
- 結果は `data/reports/goals_audit.md`、Dashboardの「🎯 最終ゴール貢献度」にも表示。

### 監査で行った是正（実績）
- 学習ゲームの3問（潤滑・オーガズム・俗説）が、尊重の記述はあってもG6の「思いやる行動」語を
  含んでいなかった → 初心者変換で**全問に思いやる行動の一文を保証**するよう修正。
- 個人差の言い回し（「人により異なり」等）を監査が取りこぼしていた → 検出語を補正。
- 結果、**整合率 100%（非貢献コンテンツ 0件）** を達成。

## 運用ルール
1. 新しいコンテンツを作ったら `goals-audit` を実行する。
2. 「非貢献」や「学習者向け必須(G2/G6)未充足」が出たら、公開前に修正する。
3. 修正できない・ゴールに資さないコンテンツは公開しない（削除する）。
