# YouTube動画 選定基準

**目的：教材の材料となる動画を、一定の品質・信頼性で選ぶ。**
YouTube動画は「一次的な教材候補」であり、それ自体は医学的権威ではない。
最終的な医学的妥当性は Knowledge Base 上で Medical Evidence Reviewer が確定する。

---

## 1. 採用条件（すべて満たすことが望ましい）
- [ ] 発信者が医療専門職・大学・学会・公的機関、または医学監修が明示されている
- [ ] 解剖学・生理学・性機能医学に基づく**教育目的**の内容
- [ ] 出典・参考文献に言及がある、または内容が教科書的事実と整合
- [ ] 個人差や「諸説あり」を適切に扱っている（断定しすぎない）
- [ ] 同意・安全・尊重の観点に反しない
- [ ] タイトル・URL・チャンネル名・公開日が取得できる

## 2. 除外条件（1つでも該当したら不採用）
- [ ] 性的に煽る/嗜好目的で、教育を装っているだけの内容
- [ ] 「必ず」「全員」「絶対」など**断定的な効果**を主張（例：整体で不感症が必ず治る）
- [ ] 出典不明の俗説・都市伝説を事実として提示（例：Gスポットは独立器官で全員が…）
- [ ] 特定商材・施術へ誘導するための誇大表現が主目的
- [ ] 差別的・固定観念を助長する表現（女性を一括りにする 等）
- [ ] 医療行為の自己判断を助長（受診不要と断定 等）

## 3. エビデンス評価（動画単位の目安 → 主張単位で再評価）
動画全体の信頼度を A〜D で仮置きし、`sources.reliability` に記録する。
**最終的な採否と強さは主張(claim)単位**で Reviewer が決める。

| レベル | 目安 | 例 |
|---|---|---|
| A | 教科書・ガイドライン水準の確立事実を、専門職が解説 | 大学講義、学会公式 |
| B | 複数研究で一貫する内容を、監修つきで解説 | 医師監修チャンネル |
| C | 限定的・議論のある内容、一次情報が弱い | 専門家個人の見解 |
| D | 俗説・根拠不十分・断定過剰 | 無出典のライフハック系 |

- **D は不採用**（教材の材料にしない）。C は「要検証」前提で参考のみ。
- 1本の動画に強弱が混在する場合、動画は採用しつつ**弱い主張は needs_review / rejected** にする。

## 4. 記録（ソース台帳に残す項目）
- source候補ID（暫定）／タイトル／URL／チャンネル名／公開日
- 採用可否と理由（除外条件に触れた場合はどれか）
- 動画全体の仮エビデンス（A/B/C/D）と根拠
- 医学的に疑わしい箇所のメモ（後で needs_review/rejected に回す）

## 5. 判断に迷ったら
- 断定的効果・俗説・煽情のいずれかを感じたら**保留**にし、医学レビュアに相談。
- 「面白いが根拠が薄い」動画は、採用しても**強い主張には使わない**（C以下として扱う）。
