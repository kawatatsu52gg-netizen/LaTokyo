# コンテンツ制作 標準ワークフロー（Instagram / YouTube / スライド）

全コンテンツは **Knowledge Base からのみ**生成する（`generate` / `content-all`）。
生成物は下書き（draft）であり、公開前に**媒体別チェック**と**人間確認**を通す。

共通の前提：
- 生成物は `data/content/<主題>/<形式>.md` に出力され、出典・エビデンス・安全注記つき。
- KBを更新したら該当主題を再生成して最新化する（`content-all "<主題>"`）。
- どの媒体でも、**出典・免責・個人差・同意/安全**の要素は削らない。

---

## A. 共通ステップ（どの媒体でも最初に行う）
1. 主題を決める（topic名 または entity名）。例：「陰核」「骨盤底筋」「性交痛」。
2. KBが最新か確認（必要なら [KB_UPDATE_CHECKLIST.md](KB_UPDATE_CHECKLIST.md)）。
3. 生成：`python -m src.pipeline generate <形式> "<主題>"`。
4. 事実・出典を目視確認（KB由来で正しいか、断定が無いか）。
5. 媒体別チェック（下記）→ 責任者確認 → 公開。

---

## B. Instagram
### B-1. カルーセル
- 生成：`generate instagram "<主題>"` → `instagram_carousel.md`
- チェック：
  - [ ] 表紙が主題を明示／1スライド1メッセージ
  - [ ] 各事実に根拠レベルが付く／出典スライドがある
  - [ ] まとめに「個人差・対話・同意」がある
  - [ ] ハッシュタグが教育文脈（煽情的でない）
  - [ ] 画像化時も出典・安全注記を省略しない
### B-2. リール
- 生成：`generate reel "<主題>"` → `instagram_reel.md`
- チェック：
  - [ ] フックが誇張・煽情でない
  - [ ] ポイントが事実ベース／尺（〜45秒）に収まる
  - [ ] 末尾に個人差・受診の一言がある

## C. YouTube
### C-1. 動画台本
- 生成：`generate youtube "<主題>"` → `youtube_script.md`
- チェック：
  - [ ] 導入で「教育目的・個人差・同意」を明言
  - [ ] 各セクションに根拠レベルと出典が付く
  - [ ] まとめ/CTAが商材誘導でなく学習に向く
  - [ ] 概要欄に参考文献（出典）を転記する
### C-2. ショート
- 生成：`generate short "<主題>"` → `youtube_short.md`
- チェック：B-2 に準ずる（尺〜50秒、煽情NG、安全一言）。

## D. スライド（HALII Academy）
- 生成：`generate slide "<主題>"` → `halii_slide.md`
- チェック：
  - [ ] 冒頭スライドで教育目的・個人差・同意を明示
  - [ ] 各スライドに根拠レベル、発表者ノートに出典
  - [ ] まとめ＋出典スライドがある
  - [ ] 登壇者が口頭で「断定しない・受診を促す」を補足

## E. その他の形式
- 患者向け：`generate patient "<主題>"`（平易・安心・受診の目安を必ず残す）
- 整体師向け：`generate practitioner "<主題>"`（治療効果の断定禁止・医療と教育の区別）
- ブログ：`generate blog "<主題>"` ／ FAQ：`generate faq "<主題>"`
- メール講座：`generate email "<主題>"` ／ チャットボット：`generate chatbot "<主題>"`
- 一括：`content-all "<主題>"`（全14形式）

---

## F. 媒体横断の最終チェック（公開直前）
- [ ] KB由来であり、KB外の情報を足していない（SSoT遵守）
- [ ] 出典・エビデンス・免責・個人差・同意/安全が保持されている
- [ ] 煽情・断定・テクニック偏重・固定観念が無い
- [ ] 主題名・用語が正式名称（俗称は補足に留める）
- [ ] 責任者（必要に応じ医療者）の確認済み
- [ ] 公開ログ（媒体・URL・日付・担当・使用主題・kb_version）を記録

## G. 更新時
KBを更新 → `content-all "<主題>"` で全形式を再生成 → F を再チェック。
KBが真実なので、全媒体が矛盾なく最新化される。
